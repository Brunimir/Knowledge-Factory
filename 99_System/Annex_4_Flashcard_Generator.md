# Annex 4 — Flashcard Generator — SUPERSEDED

**This annex is retired.** It described a different, dead model: per-concept
card files (`{Title} - Definition.md`), `topic:` frontmatter, `#card #definition`
tags, and a `flashcards_export.csv` that nothing else references. It does not
match the live plugin configuration (folder-based deck, flashcards-obsidian
v2 list-item cards `- Question :: Answer`, no `#card` line) and would produce
cards the plugin parses wrongly.

**Canonical replacement:**
- Live pipeline spec (Phases GF-0 → GF-4) → `docs/flashcards-pipeline.md`
- Per-batch file skeleton (GF-2 format) → `99_System/Flashcard_File_Template.md`
